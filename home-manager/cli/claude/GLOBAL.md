# markdown 書く時の原則

- アルファベットの前後には半角スペースをいれる
- 括弧は可能な限り半角を使う
  - `「」`は日本語の慣習を破壊しないために全角のままでOK
  - `()` や `[]` は半角を使う
- その他の記述については [Microsoft 文書作成スタイルガイド](https://learn.microsoft.com/ja-jp/style-guide/welcome/)に従う

# git を操作するときの原則

- worktree 機能を使わない
  - ターミナルのプロンプトにアイコンが出ない、 `git switch` が使えなくなるなどが嫌
  - 作業ブランチを変える際に必要であれば `git stash` を使用すればアイコンが出るのでこちらを使うこと
- 勝手に commit しない
  - commit する前に内容をこちらで精査する
